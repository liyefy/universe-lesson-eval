# 视口、排版与素材

依据本轮确认的 NB宇宙规则「视口规范」、[项目根规则](project-setup.md)、[项目公共索引](project-setup.md) 及当前适用设计。按需读取 项目 `universe-responsive-ui/references/acceptance-checklist.md` 与 项目 `r3f-best-practices` 规范（定位见 [项目接入](project-setup.md)）。

保留满铺主舞台、单层气泡及跨阶段素材一致的既有验收目标，并在计划中记录来源/版本/适用视图。1024×768 是外部规则的首要基线；其他设备按本轮范围覆盖。记录实际 CSS 视口、内容区、DPR、浏览器和输入方式，不把模拟视口称为真机或宿主验收。分级只用 [labels.md](labels.md)。

## 可重复的运行测量

VIEW-01/02/03 的适用 case 使用 `browser`，同时保存原始公开 DOM 几何、截图和脚本执行。full 按来源节点逐一声明适用性，覆盖面板开关及已冻结的尺寸/状态；适用范围和契约见 [schema-v2.md](schema-v2.md)。不能只列已知能通过的节点，或把相机函数存在当作侧栏避让成立。

`scripts/check_viewport.py` 读取原始观测 JSON 与截图，计算盒模型误差、四边像素覆盖、主体连通区域及可用区边距。PNG 使用标准库解码；JPEG/WebP 需要可选的 Pillow，按实际文件头识别，不改写原截图。输入观测包含实际 `source/build_id/node_id/state/viewport/captured_at`、`host`、`scene` 和 `occluders`；矩形为 CSS px 的 `{x,y,width,height}`，遮挡项为 `{kind:"panel"|"ui",rect}`。面板决定可用区域；按钮/工具栏仅遮罩像素采样，不冒充整个侧栏。截图按像素尺寸与 CSS 视口等比换算。

VIEW-01 始终测量场景与宿主四边的完整盒模型。像素默认采宿主边缘；只有一整条边被实测 `panel` 完全遮住时，才在该方向的可用区域边界采样，例如底部 Sheet 上方。输出记录 `boundary`、采样线与连续采样段、遮挡原因及面板矩形，不声称看到了面板后方像素。普通 UI 遮挡或可用边仍不可见时保持未验证；不能任意向内移动采样线绕过黑边。

在 case 的 `viewport_assertions` 冻结阈值。例如经确认的明亮全景可采用：

```json
{
  "VIEW-01": {"box_tolerance_px":2,"edge_background_rgb":[0,0,0],"edge_color_tolerance":18,"edge_min_non_background":0.95},
  "VIEW-02": {"center_tolerance_px":8,"subject_min_rgb":[245,235,150],"subject_max_rgb":[255,255,255],"subject_min_area_px":50},
  "VIEW-03": {"safe_margin_px":40,"subject_min_rgb":[245,235,150],"subject_max_rgb":[255,255,255],"subject_min_area_px":50}
}
```

每个 case 只采用对应规则的对象。以上是特定明亮主体的识别配置，不是所有科学场景的统一颜色/构图标准。阈值与主体特征必须有本轮依据；识别不到、出现相近候选、全食使主体颜色改变、缺少解码器、图像格式不支持或遮挡导致无法测量时标为未验证，不能放宽阈值凑通过。黑色宇宙背景不适用日间黑边像素判据；应采用能证明该场景真实覆盖的观测方法，并保留图片与测量依据。

读取截图须实际查看，确认识别的是科学主体。测量脚本只处理支持的像素/几何命题；科学语义、全食时的感知可读性和连续运动仍按各自证据边界检查。运行记录、哈希与字段校验不能证明采集者从未漏看原文或伪造观测。

## VIEW-01 全屏画布与主舞台满铺

- 外部规则要求 Canvas 保持完整场景底座，不随侧栏开闭修改 CSS 宽高或重建 Renderer。按实际应用内容区定义满铺边界；嵌入环境不盲目使用顶层屏幕尺寸。
- 对已确认为背景/全景主舞台的视图，检查四边覆盖、面板下方延展与非预期留黑；明确设计的画中画、图表或局部视窗不适用主舞台满铺要求。
- 自动测量宿主与 Canvas/舞台盒模型，比较侧栏开关及 resize 前后；观察是否拉伸、黑屏或课程状态丢失。容器覆盖不等于渲染内容覆盖，必要时再检查实际画面。
- 黑色宇宙背景不是“黑边”的充分证据；需证明存在违背该视图设计的内缩、断层或空隙，不能由 CSS 关键字自动定罪。
- 证据：宿主范围、边界测量、实例生命周期及四边实际画面/过渡。

## VIEW-02 侧栏避让与旋转中心

- 核对当前允许的相机视口偏移、控制器目标或公共避让机制；不得为避让改变模型世界转轴。共享 CSS 机制与外部文字存在分歧时按 [prepare.md](prepare.md) 核对实际权威，不预设已有实现自动合规。
- 开关侧栏、过渡中反向开关并旋转，验证主体位于实际可用区、关闭后回中、旋转中心稳定。
- 几何中心/轨迹可确定时用测量断言，过渡同步和突跳仍无法量化时用过程观察。
- 证据：面板到避让的调用链、实际可用区、过渡与旋转记录。

## VIEW-03 模型投影与安全边界

- 覆盖 1024×768 默认/侧栏展开/关键科学终态及本轮约定视口。测量模型在屏幕上的投影、关键观察部位、可用区和遮挡，不能用世界包围盒或 Canvas 边框代替。
- 外部规则中“至少 40px 安全边距”与“短边占比通常 70%–75%”须保留各自含义：前者按其适用视口/边界检查，后者是饱满展示的通常目标，不自动当精确硬阈值。记录测量坐标与单位；缩放/嵌入场景有冲突先核对来源。
- 真实裁切、关键部位被遮或无法辨认时记录实际影响；不因为比例偏离经验区间便自动判严重。
- 证据：投影测量方法、关键部位与边界标记、实际画面。

## VIEW-04 教学结构与单层气泡

- 按根规则核对探索结构：已选假设（可无）、公共单行序号标题、单层操作卡/讲解、前后操作。标题不重复，不出现可跳转的整套探索目录；本步真实取证进度仍允许。
- 按公共索引，探索段落正文使用 `LearningGuideSegmentedText`。段落自身为气泡卡片时，包裹它的 `LearningGuideCard` / `LearningGuideActivity` 使用公开 `presentation="plain"`，避免外层内容卡再形成一层大气泡。
- 核对适用组件、结构与计算样式，再看实际层级；不能要求所有祖先（包括面板）背景都透明，也不能只因找到某个 prop 就认定视觉已通过。
- 检查主操作、正文、滚动和展开术语的可用性；布局拥挤先记录呈现问题，不建议删去必要教学文本。
- 证据：真实结构、相应公共 API、边界/样式与视口画面。

## VIEW-05 指针与手势归属

- 核对拾取、拖拽、滑块、标签、相机和浮层的坐标来源、pointer-events、层叠、捕获/取消清理；区分 CSS 与物理像素。
- 在面板开关、尺寸变化后真实点击/拖动并取消，验证目标命中、UI 操作不误带动相机、取消后可恢复。
- 公开 DOM 命中和状态可自动断言，三维可见命中效果不足时补实际观察。
- 证据：输入位置/方式、布局条件、前后状态与连续操作记录。

## VIEW-06 响应式与目标环境

- 对本轮要求的横竖屏、矮屏、安全区、旧浏览器或 WebView，核对既有 rem 基线、安全区只应用一次、关键 CSS 的适用降级。
- 真实环境验证正文、状态、主操作、媒体与课程状态保持。现代浏览器模拟视口不能证明 Chrome 66 或宿主协议已兼容。
- 必查环境不可用时保留未验证，既未要求也不适用的环境不自动扩大任务。
- 证据：环境矩阵、实际截图/断言、状态保留过程与未覆盖条件。

## VIEW-07 跨阶段素材与画中画一致

- 对同一科学对象、同一观察视角在提问/探索/结论间重复出现的视窗，检查是否复用已建立的资产与渲染语言；已确认写实地景不应无依据换成风格脱节的简图。
- 明确改变教学用途的示意图、真实授权的设计变更或有说明的性能降级，按对应需求检查，不设“所有阶段必须 100% 相同素材”或“任何 SVG 都是降级”的通用禁令。
- 静态追踪资产/组件复用；模型仅判断来源已明确但视觉一致性仍需感知的部分。圆角、阴影和裁切遵从当前公共设计令牌，不编造固定 18px 标准。
- 证据：相同视角的跨阶段原始画面、资产/调用链、允许差异的来源及其教学影响。
