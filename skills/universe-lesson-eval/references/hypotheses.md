# 假设的论证与揭示

依据当前 [项目根规则](project-setup.md) 和外部 NB宇宙规则的完整论证条款；组件事实查 [项目公共索引](project-setup.md)。不以旧阶段名替代论证判断。

为全部客观假设建立“原始 ID/原文/正误 → 必要论据与操作 → 完成论证的句子、节点、全部必要 cue → 首次揭示”映射。论证充分性可需要模型；集合、引用和门禁优先确定性检查。

音频后置且本轮尚未接入时，原文、全量映射、正误和非剧透范围仍检查；依赖真实 natural-ended 的实播时刻和音效按计划 N/A，不虚构替代完成逻辑。

## HYP-01 全量客观映射

- 核对专题全部假设、ID、原文、客观正误和反馈目标，包含学生未选项与同一步充分论证多项的情况。
- 用确定性集合/引用检查发现过滤、替换和遗漏；初选影响实际分支时通过公开 UI 切换选择核对。
- 预期：论证哪项就揭示对应项，同步完成多项时展示这些项，尚未充分论证的项不出现。
- 证据：全假设映射、实际输入与卡片 ID/文本；不把错误假设本身当作科学缺陷。

## HYP-02 完整论证门槛

- 先通读整个相关探究链，识别跨节点前提、必要操作、每段论据及完成判断的句子。不能只给模型最后一句结论。
- 论证充分性使用 model case 时写明判断理由与原文证据；已确认映射的门禁实现另用 static/browser case 核对全部必要操作与 cue。
- 进入音频阶段后，验证中间现象、采样未完成或前置必要 cue 尚未自然结束时不揭示；只听最后短句不能绕过前置论据。
- 证据：假设到完整论证的映射、必要操作、各 cue 的真实播放顺序及揭示前后状态。停留时长不是充分论证证据。

## HYP-03 真实结束与首次揭示

- 静态核对当前节点/播放轮次、真实 cue、natural-ended 守卫及通用 `playCardPopSound()` 调用。暂停、停止、切步、失败和旧回调均不得当作自然结束。
- 已接音频时，通过实际播放检查负向路径，再让全部必要 cue 自然结束；最后必要 cue 结束时首次揭示本次允许集合，不额外等待下一次操作。
- DOM 揭示状态和时间序列可用浏览器断言；实际声音及音画时机需要真实收听。记录可观察时间，不自造毫秒容差，也不把正常渲染帧延迟直接判违规。
- 证据：操作、播放序列、前后卡片状态及声音观察。伪造 ended、改 Store 或直接调用回调不能作为实播验收。

## HYP-04 原文与公共卡片

- 卡片正文字符级复用初始假设文本；检查公共组件、标题“假设”、无编号/额外修饰以及正误对应。
- 实页核对正确项绿色圆底对勾、错误项红色圆底叉号、公共边框与暗色渐变、文字完整可读。可确定的 DOM/样式事实优先自动断言；实际遮挡/可读性按需视觉观察。
- 多卡、小视口及滚动状态按本轮计划覆盖；引用了公共组件不自动证明展示正确。
- 证据：字符差异、组件/样式调用链与真实状态画面。

## HYP-05 返回、重播与重新学习

- 区分播放轮次和学习轮次：同次已揭示卡返回/重播时静默保留，不重复弹出或弹声；显式重新学习清空并重走完整门禁。
- 通过真实 UI 覆盖未揭示/已揭示前态、前后返回、重播、快速切换与重新学习；旧播放回调不得影响新轮次。
- 动画重播初态另按 [motion.md](motion.md) 判断，不能因动画归零就同时清除已揭示集合。
- 证据：各路径起点、操作、终态和实际音效次数；未听音不声称单次音效已通过。
